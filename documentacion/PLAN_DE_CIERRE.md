# Plan de cierre del proyecto

## Logros de Fase 2

- Estructuras `Materia`, `Vertice` y `Grafo` funcionando como base del análisis.
- Flujo visible de selección de carrera, consulta de malla y ruta sugerida.
- Prueba unitaria existente para lectura y ordenamiento de un caso sin ciclos.
- Bitácora inicial y casos de prueba documentados.

## Aspectos por mejorar

1. Reemplazar los datos de demostración por pensums oficiales validados.
2. Agregar importación de archivos desde la interfaz y validaciones de formato.
3. Automatizar pruebas de ciclos, prerrequisitos inexistentes y casos borde.
4. Mostrar la ruta por ciclos o semestres, no únicamente como una secuencia.
5. Añadir persistencia y una pantalla para administrar carreras.

## Guion sugerido para el video (5–10 minutos)

1. Contexto y problema que resuelve el analizador (1 min).
2. Arquitectura MVC y estructuras de datos elegidas (2 min).
3. Demo: elegir carrera, revisar la tabla y generar la ruta (3 min).
4. Pruebas y bitácora de dificultades (1–2 min).
5. Autocrítica y plan de cierre (1 min).
